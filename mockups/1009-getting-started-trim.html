About this version

Revised from the five-frame version published earlier today (commit e73e1a2, kept in git history): adds the ghosts of every removed block in F1, the Toast "No" branch (F5) and the done-state Items step (F7) as their own frames, and the A/B question on the three number cards, which the brief asks Kiran to decide rather than the mockup.

Where every number already comes from

GET /tenant/onboarding: checklist.percent + sections[] draw the progress line AND the OPEN tile's percent/steps-left (journeyProgress, one function); sections[].whatYouNeed / timeEstimate / doneMeans / guides / skippable fill a tile's ⓘ pane; vendors[] draws the Back door strip; nextAsk.fix.posKind / posLabel / posGuide (issue #532) name the POS and its connect/check/export steps — PosStepBody reads the same fields off settings.onboarding.pos when browsing to a step that is not the current ask; catalogShelved {published, staged} (#479) is the "271 on shelves · 6 held" line; askHistory[] names Items/Sales as done. Nothing here needs a migration or a new route.
